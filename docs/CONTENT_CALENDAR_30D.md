# nambac 30일 콘텐츠 캘린더 (베트남 시장)

목표: DAU 성장을 위한 `매일 발행 + 공유형 콘텐츠` 운영  
사용법: 매일 아래 1개 주제로 퀴즈를 만들고, 운세 1개와 함께 배포

## 운영 원칙

- 하루 콘텐츠: `퀴즈 1개 + 운세 1개`
- 주 2회: 논쟁형/비교형 주제
- 주 1회: 대형 테마(주간 챌린지)
- 카피 톤: 베트남 Gen Z (짧고 강한 훅)

## 매일 호출 방식

Cursor에 들어오면 아래 한 줄만 입력:

`오늘 콘텐츠 호출`

또는 터미널에서:

`npm run content:today`
